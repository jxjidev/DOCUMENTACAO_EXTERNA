# Azure Wiki

**Wiki com Integração Azure**

Quando a integração com o Azure está ativa, o comportamento muda:

* A tela de **Estrutura de Pastas** passa a permitir apenas a **sincronização**
* As pastas exibidas são provenientes da Wiki já existente no Azure
* Não é possível criar ou alterar a estrutura diretamente pela aplicação
* A Wiki funciona como um espelho para visualização dos conteúdos sincronizados
